# DevForum Evidence Gate

DevForum material is valuable engineering evidence but is not automatically an engine guarantee.

For every candidate:
1. Extract the exact technical claim.
2. Identify date/version/context when available.
3. Separate observed behavior from opinion.
4. Search official Roblox documentation for the same API/behavior.
5. Record supporting and contradicting evidence.
6. Mark applicability and non-applicability.
7. Assign evidence status.
8. Promote only when evidence is sufficient.

Preferred statuses:
`CANDIDATE`, `CONTEXT_SPECIFIC`, `CONFLICTING`, `STATICALLY_VERIFIED`, `CROSS_VERIFIED`, `SUPERSEDED`.

Never rewrite “a developer observed X” into “Roblox guarantees X” without evidence establishing the guarantee.
