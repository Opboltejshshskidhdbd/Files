## SYNTAX-001 — Structural syntax defects are root-cause classes, not line fixes
- Status: STATICALLY_VERIFIED
- FailurePattern: generated Luau can contain missing/extra block terminators or malformed nested control-flow/callback structure.
- RootCause: large source composition can drift structurally; reported compiler location is only a symptom boundary.
- Prevention: perform whole-source structural audit and revalidation after repair.
- Detection: search equivalent block/control-flow manifestations across current source.
- Evidence: packaged Level 1/Level 2 syntax workflow and regression corpus.
