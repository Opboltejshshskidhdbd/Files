# Knowledge Expansion + Syntax Learning Acceptance Benchmark

A. Extra `end` — Level 1 identifies structural mismatch; Level 2 reproduces it.
B. Missing `end` — repair actual source and revalidate.
C. Multiple independent syntax defects — do not stop at first diagnostic.
D. Repair-induced defect — second pass must detect contamination.
E. Repeated same defect — exhaust all current-source manifestations.
F. Nested callbacks — regression lesson must generalize to composition.
G. Advanced valid Luau — types/generics/type packs must not be rejected by knowledge policy.
H. Roblox-specific implementation — distinguish syntax validity from Engine API correctness.
I. DevForum claim — classify as evidence and compare with official docs.
J. Community conflict — preserve conflict until authority/evidence resolves it.
K. Deprecated API — prefer current official replacement when documented.
L. Real generated failure — produce learning receipt only after source repair and revalidation.
M. Learned failure recurrence — classify `LEARNED-PATTERN REGRESSION`, repair, strengthen prevention.
N. Privacy — generalized lessons must not contain usernames, private project names, paths, IDs, assets, or private source identifiers.
O. Source truth — current source outranks README, audit, narrative, and prior claims.

For every benchmark: record evidence status, exact files/regions inspected, repairs, post-repair validation, whole-source exhaustion, second-pass result, and runtime verification separately.
